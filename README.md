# 🎮 2D RPG in Unity

Projeto de desenvolvimento de um **RPG 2D utilizando Unity e C#**, criado para praticar programação e aprender mais sobre desenvolvimento de jogos.

## 🛠️ Tecnologias

![Unity](https://img.shields.io/badge/Unity-000000?style=for-the-badge&logo=unity&logoColor=white)
![C#](https://img.shields.io/badge/C%23-239120?style=for-the-badge&logo=csharp&logoColor=white)

## 🎯 Objetivos

- 🕹️ Praticar o desenvolvimento de jogos 2D.
- 💻 Aplicar conceitos de programação com C#.
- 🧠 Aprender a estruturar e organizar um projeto na Unity.
- 🚀 Evoluir minhas habilidades em desenvolvimento de jogos.

## ▶️ Como executar

1. Clone este repositório.
2. Abra o projeto pelo **Unity Hub**.
3. Aguarde a importação dos arquivos.
4. Abra a cena principal e clique em **Play**.

## 📚 Sobre o projeto

Este repositório faz parte da minha jornada de aprendizado em desenvolvimento de jogos, reunindo os conhecimentos adquiridos durante o estudo de RPGs 2D com Unity.
